# Dundas East Animal Hospital — website concept

A responsive website redesign and interactive client payment portal demo, prepared by Bird E Consulting for discussion with Dundas East Animal Hospital.

## Demo features

- Refreshed homepage, service overview, contact information and click-to-call links.
- Four illustrative pet products, category filters, cart quantities and totals.
- Fictional invoice lookup: `DEMO-1042`, client code `PET-2026`.
- Checkout simulation and demonstration receipt. **No payment processing, card fields, real invoices, orders, accounts, or personal data collection.**
- Keyboard-accessible tabs, responsive layouts, reduced-motion support and semantic HTML.

## Run

Serve this folder with any static HTTP server, for example `npx --yes serve .`. No build is required. Publish the root of `main` with GitHub Pages.

## Content and assets

Clinic name, address, phone, email and service categories were checked against https://dundasvets.com/ on October 21, 2026. All product names and prices are invented examples; all prices are CAD and illustrative totals include any applicable taxes. No clinic hours, reviews or staff credentials are invented. The design is a proposal and is not represented as the clinic's live website. The site requests search engines not to index it.

Pet photography is served from Unsplash. Fonts are DM Sans and Manrope from Google Fonts. Package illustrations are made in HTML/CSS. These external assets require an internet connection; system fonts remain available as fallbacks.

## Before real launch

Have the clinic approve copy, products, pricing, taxation, pickup policies and imagery. Integrate a hosted payment provider with server-side invoice verification, verified payment webhooks and appropriate privacy controls. The demo is intentionally static and must not be used to accept actual payments.
